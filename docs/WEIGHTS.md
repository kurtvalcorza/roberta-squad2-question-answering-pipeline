- Upstream weight license: CC-BY-4.0 (`license: cc-by-4.0` in the pinned upstream README front matter). Attribution required by the licence: the checkpoint was created and published by **deepset** (Branden Chan, Timo Möller, Malte Pietsch, Tanay Soni) at https://huggingface.co/deepset/roberta-base-squad2 and is redistributed here **unmodified**; the licence text is at https://creativecommons.org/licenses/by/4.0/. Keep this attribution with any copy of the weights.
- Local layout: `weights/roberta-base-squad2/` holds the 7 files listed in `dimer-base-manifest.json` (`config.json`, `merges.txt`, `model.safetensors`, `special_tokens_map.json`, `tokenizer_config.json`, `vocab.json`, upstream `README.md`; there is no `tokenizer.json` at this revision, so `AutoTokenizer` builds `RobertaTokenizerFast` from `vocab.json` + `merges.txt`; `totalBytes` 497,620,185) with byte size and SHA-256 for each. `verify_snapshot()` in `src/roberta_question_answering_pipeline/pipeline.py` checks all of them before any load; `stage_missing_files(allow_download=True)` fetches only absent entries at the pinned revision into that directory. `.safetensors` files are git-ignored; the Git repository does not vendor the checkpoint.

DIMER may mirror the pinned checkpoint in its model store under those terms with the attribution carried alongside it.
- Loader trust boundary: Transformers `RobertaForQuestionAnswering` + `AutoTokenizer` with `trust_remote_code=False`; the loader reads only the verified local directory (`local_files_only=True`) and falls back to the Hub at the pinned revision only when `allow_download=True` is passed explicitly.

## Adaptation corpus (not redistributed)

- Source: AdversarialQA v1.0 (Bartolo et al., TACL 2020) — `https://adversarialqa.github.io/data/aqa_v1.0.zip`, 9,018,914 bytes, SHA-256 `f4f3c23224a5060b28c35e35581bd5cf46256dda3665418fb83d036d0e0c93cf`; only the members `3_droberta/train.json` (10,000 questions) and `3_droberta/dev.json` (1,000 questions, 21 articles) are read; `test.json` ships without answers and is unused.
- Licence: CC BY-SA 3.0 (project site; the Hub mirror `UCLNLP/adversarial_qa` lists CC BY-SA 4.0). Attribution is carried in `CORPUS_LICENSE` and in every result export's `corpus` block. The passages are SQuAD 1.1 Wikipedia paragraphs (CC BY-SA).
- Handling: `fetch_corpus` verifies the byte count and SHA-256 before the zip is read, reads the two members with `ZipFile.read` (no `extractall`), and caches the verified zip under `weights/adversarialqa/` (git-ignored). The repository ships no copy of the corpus; only the digest, the seed (`SAMPLE_SEED = 42`), the split sizes (`SAMPLE_SPLIT`) and the sample filters are committed, which reproduce the 1,000 / 200 / 400 records and their digests exactly.
- Adapter artifacts: `save_artifact` writes `adapter.safetensors` (the trained `roberta.encoder.layer.*` and `qa_outputs.*` tensors only, 56,713,104 bytes for the default two blocks plus the head) plus `manifest.json` carrying `format` `org.valcorza.roberta-base-squad2.adapter.v1`, the base `model_id` / `model_revision` / `weight_sha256`, the tensor list and the file SHA-256; `load_artifact` refuses any mismatch. Adapters are derived works of the CC-BY-4.0 weights and of whatever corpus trained them; an adapter trained on the AdversarialQA sample inherits its CC BY-SA attribution and share-alike obligations.
